OPTIONAL: CODE EXISTENCE CHECK

Without files here, the engine checks code FORMAT only.
Put official code lists here to also check that each code really exists:

  icd10_codes.txt  - ICD-10-CM code list (free from CMS: "ICD-10-CM Code Descriptions" /
                     order file for the current fiscal year, e.g. FY2027 effective Oct 1, 2026)
  hcpcs_codes.txt  - HCPCS Level II code list (free from CMS, quarterly update)
  cpt_codes.txt    - CPT codes (CPT is licensed by the AMA — use only if you/your client hold a license)

Format: plain text, one code per line (a description after the code is fine;
a leading order number, as in the CMS order file, is skipped automatically).
Update these files whenever CMS releases a new code set.
