PORTFOLIO SAMPLE - DEMO / FAKE DATA DISCLOSURE
================================================

Everything in this folder is a self-made demo, not a real client project.

- Claims_Sample.csv, medical_test_claims.csv, and all patient/claim IDs,
  NPI numbers, policy numbers, and amounts shown in the screenshots and
  sample Excel report are randomly generated / fictional. No real patient
  data, provider data, or payer data is used anywhere in this project.
- Claims_Audit_Report_SAMPLE.xlsx, Claims_1_RawClaims.png,
  Claims_2_AuditSummary.png, and the project cover images/video are all
  generated from that same synthetic sample data, purely to demonstrate
  what the tool's output looks like.
- This is a format/data-quality validation demo only (NPI check-digit,
  CPT/HCPCS and ICD-10 format checks, duplicate/timely-filing checks) -
  it is not a payer-adjudication or eligibility service, and no real
  claims were ever submitted anywhere.

If you're a potential client reviewing this: happy to run the same
pipeline on a small sample of your real (de-identified) data so you can
judge the actual output quality before committing to a full project.
